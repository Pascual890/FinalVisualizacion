# Archivo de Cregon

Producto final de Visualización de datos. El archivo del reino de Cregon quedó
abandonado después de la caída de los nobles; el usuario entra y explora lo que
quedó: la denuncia, la carta del reino, el censo, las cuentas, el libro de
tierras, el libro de linajes, el libro de la guardia, la crónica y la daga.

**Sitio:** <https://pascual890.github.io/FinalVisualizacion/>

## Requisitos

Pensado para usarse preferiblemente en computador, con Chrome o Edge
actualizado. No necesita un equipo potente, pero sí aceleración gráfica activa.

Si se ve lento o entrecortado:

1. Activar en Chrome **Configuración → Sistema → Usar aceleración gráfica
   cuando esté disponible** y reiniciar el navegador.
2. Actualizar el navegador.
3. Usar una ventana más pequeña o bajar la resolución de la pantalla.

## Cómo abrirlo en local

Usa módulos ES y `fetch`, así que no funciona con doble clic.

```bash
python serve.py
```

Luego abrir <http://localhost:8000>.
